T0019 第三轮已修改测试并完成 Pi 自检，但提交前范围校验拒绝新增 bytecode。旧扩展把它记成“提交结果不确定”并暂停，控制器又丢失细节，统一显示“用户暂停或退出”。本次修复原生 Pi 的这一流程。

- 明确的提交前范围拒收留存请求、快照、内容和事件，返回结构化拒收；Pi 可在原契约内处理一次，不重放旧提交、不消耗新审查轮次。重复拒收或不确定结果暂停。
- 暂停原因写入 SQLite 和 Pi 会话；网络断开导致暂停请求也失败时，本地工具和轮询保持冻结。晚到的成功／失败回执不能撤销用户中止。
- 原生 Pi 默认使用仓外 Python 缓存目录。提交和显式恢复实施前，可先保存完整现场，再归档清理标准新字节码；已有文件、未知版本、链接或其他越界继续拒收，冻结审查不做清理。
