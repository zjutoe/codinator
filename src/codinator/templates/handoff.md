# Handoff template — main Codex

Before publication, check that the goal, scope, inputs, deliverables and acceptance
criteria are sufficient to execute. Resolve missing information that blocks execution,
state existing authority and handoff rules, and verify content yourself. Complete
headings alone do not establish a useful contract. Codinator checks format only.

## Goal
Describe the concrete problem and expected outcome.

## Scope and constraints
State allowed changes, existing authority, exclusions, isolation and budget boundaries.

## Required inputs
Identify context, dependencies and stable references; use None when inapplicable.

## Deliverables
Specify expected artifacts, destinations and how the recipient can locate them.

## Acceptance criteria
Give independently verifiable conditions, with stable identifiers when helpful.

## Handoff rules
State submission and help boundaries, bound tool/destination and the next handler.
